# 学习教练输入模板

当用户请求完整学习支持，但输入信息不足时，可以按这个模板快速补齐。

## 简版采集

- 你想学的技能：
- 你现在的水平：
- 你学这个是为了什么：
- 你每天或每周能投入多久：
- 你希望先得到什么帮助：

## 完整版采集

- 技能名称：
- 当前水平：完全不会 / 略懂 / 已入门 / 可独立完成基础任务
- 学习目标：兴趣 / 工作 / 面试 / 考试 / 接单 / 转岗 / 项目落地
- 时间投入：每天多少分钟，持续多久
- 学习周期：7天 / 30天 / 90天 / 长期
- 偏好方式：案例 / 练习 / 项目 / 问答 / 测试 / 讲解
- 当前困难：不知道从哪开始 / 理解不了概念 / 做题不会 / 缺少反馈 / 容易中断
- 已有材料：作品 / 作业 / 失败记录 / 笔记 / 课程链接

## 采集原则

- 优先收集会直接影响建议质量的信息
- 不要为了凑模板而追问无关细节
- 如果用户明显只想先开始，先给轻量方案，再逐步补信息
