## 📐 尺寸规则（任意尺寸，但有约束）

gpt-image-2 支持**任意尺寸**，只要满足以下全部约束：

1. **最长边 < 3840px**
2. **两边都是 16 的倍数**
3. **长短比 ≤ 3:1**
4. **总像素 ≥ 655,360**（约 1024×640 下限）
5. **总像素 ≤ 8,294,400**（约 3840×2160 上限）

### ⚠️ 重要警告
> 官方原话："If the output image exceeds 2560×1440 pixels (3,686,400 total pixels), **commonly referred to as 2K, treat it as experimental because results can be more variable above this size**."

**翻译**：**超过 2K 的图属于 experimental 档位，输出质量不稳定**。
**重要 UI 工作建议不要上 4K**，直接用 2K 或 1.5K 更稳。

## 💡 实战使用法则

### Rule 1: 先低质打样，再高质出片

```powershell
# 第一次：low 快速看构图对不对
.\gen-image.ps1 -PromptFile prompt.txt -Size "1024x1024" -Quality low

# 满意了：high 出终版
.\gen-image.ps1 -PromptFile prompt.txt -Size "1536x1024" -Quality high
```

**节省**：low 档 ~$0.01，high 档 ~$0.16，省 16 倍成本。

### Rule 2: 含文字的 UI 必须 `high`
文字渲染对 quality 敏感：
- `low` → 字糊、变形
- `medium` → 大字 OK，小字糊
- `high` ⭐ → 大小字都清晰

### Rule 3: 2K 是性价比甜点
- `2560x1440 + high` = $0.22
- 比 4K 稳、比 1.5K 清晰
- 适合**最终交付的 UI mockup**

### Rule 4: 4K 只在确定需要时用
- 4K = 2K + 80% 成本
- 但官方警告"结果可能更不稳定"
- 除非做**印刷海报**或**桌面壁纸级**展示，否则不推荐

### Rule 5: 批量用 `low` 探索方向
做 5-10 个变体找方向时，全部用 low 档：
```powershell
# 一次出 4 张变体
.\gen-image.ps1 -PromptFile v1.txt -N 4 -Size "1024x1024" -Quality low
```
成本约 $0.04，几秒钟就能看到 4 个方向。

```
│
└─ 移动 app 屏预览                  → 1024x1536 / high
```

## 📊 脚本支持的档位（已配置）

`gen-image.ps1` 的 `-Size` 参数 [ValidateSet]：

```
1024x1024   ✓
1024x1536   ✓
1536x1024   ✓
2560x1440   ✓
1440x2560   ✓
3840x2160   ✓ (experimental)
2160x3840   ✓ (experimental)
auto        ✓ (让模型自己选)
```

`-Quality` 参数：`low` / `medium` / `high`（默认 `high`）

如果需要非标准尺寸（如 `1920x1080`），改脚本的 ValidateSet 即可：
```powershell
[ValidateSet(..., '1920x1088', ...)]  # 注意：1080 不是 16 的倍数，要改 1088
```
